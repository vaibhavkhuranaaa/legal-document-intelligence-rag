# Metric Glossary

## Retrieval hit rate at 8

The share of versioned benchmark questions for which at least one expected source is present in the first eight retrieved results. This measures retrieval coverage for the benchmark, not answer correctness.

## Citation-provenance validity

The share of evaluated citations whose document identifier resolves through the registered public-source boundary to the displayed source metadata. This measures traceability, not whether a legal conclusion is correct.

## Source-match score

The proportion of citations displayed with an answer that resolve to a registered public source. The score helps a reviewer identify whether the answer is inspectable. It does not measure legal correctness, completeness, or authority.

## Indexed chunks

The number of structure-aware retrieval records in the promoted Azure AI Search index. A chunk count describes corpus scale only. It is not a quality or coverage score.

## Route reachability

An HTTP success response from a named public route at a recorded time. Reachability is a point-in-time deployment check, not evidence of availability, confidentiality, security, or a service-level objective.

## Responsive overflow

The difference between a page's scroll width and client width at a named viewport. A result of zero confirms no horizontal overflow for that page and viewport. It does not replace assistive-technology testing.

## Touch target height

The rendered height of an interactive control at a named mobile viewport. The release target is at least 44 CSS pixels for primary navigation and controls.
