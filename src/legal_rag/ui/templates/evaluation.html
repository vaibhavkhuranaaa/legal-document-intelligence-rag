How the checks work

  1. 01

    Run the question set

    Submit each versioned sample question against the current public-source index.

  2. 02

    Inspect retrieval

    Check whether the expected source appears among the first {{ report.retrieval_k }} source excerpts.

  3. 03

    Resolve provenance

  4. 04

    Publish the aggregate

    Display aggregate results only after the full release check succeeds.

Interpretation boundary

Retrieval and provenance can show that an answer is inspectable. They cannot establish that a legal interpretation is correct, complete, or appropriate for a matter.
